## Assumptions

- [README.md](README.md) describes Draft Room as "A fantasy football squad
  builder built for agents" and says it was built for the WebMCP challenge.
  This suggests a demonstration of human and agent collaboration.
- The likely audience is people who want to try an agent in a shared squad
  builder. The README describes one XI, a £100.0m budget, and fourteen WebMCP tools.
- A likely outcome is that an agent improves squad decisions through
  scenarios, atomic plans, and the manager's brief. The README presents these
  as the reason to use an agent.
- The README describes no accounts, backend, or live stats, with a draft that
  resets on reload. It labels prices, projections, and probabilities as
  illustrative. Treat these as existing limits, pending scope confirmation.
- [DESIGN.md](DESIGN.md) records the second design direction on 2026-09-02.
  It centers WebMCP and the floodlit pitch. Whether this remains the intended
  direction is unconfirmed.
